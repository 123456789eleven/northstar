12 questions
Will I lose my data?

Your data lives in your browser on your device. Clearing site data for Northstar, using a browser’s “clear everything” option, or losing the device can erase it. Without sync or a backup there is no other copy, so export a JSON backup from Settings regularly. Northstar nudges you if you have never exported one.

How do backups work?

In Settings, Export backup downloads one JSON file of everything. Import restores it as a single step, so a failed import cannot leave things half-written. The file is readable, so store it like any personal document.

Link to this answer

What if I forget my sync passphrase?

If you still have your one-time recovery code, you can use it to regain access. If you lose both the passphrase and the recovery code, nobody can decrypt the cloud copy, including Northstar and Supabase. Each device keeps its own readable copy, so export a backup and set sync up again.

Link to this answer

Can I use it on more than one device?

Yes. Turn on encrypted sync in Settings on each device, with your own Supabase project and the same passphrase. Or skip sync and move data by exporting a backup on one device and importing it on another.

Link to this answer

How do bank connections work?

By default they do not. You export a CSV or OFX/QFX file from your bank and import it; Northstar never asks for bank credentials. There is an optional live feed through SimpleFIN, off by default, which uses a small relay in your own Supabase project. See the privacy explorer for exactly what it sends.

Link to this answer

How much does it cost?

Nothing. It is free to use, with no ads and no accounts. Sync uses a Supabase project that you create, which has its own plan and limits.

Who built it?

One person, mainly for their own use, and then made available to anyone. There is no company behind it and no data collection to fund.

Link to this answer

Is it open source?

The source code is in a public repository, so it is viewable. A license has not been chosen yet, so please treat it as viewable but not yet licensed for reuse.

Link to this answer

Does it work offline?

Yes. After the first load, the app opens without a connection and everything that works on local data keeps working. Sync, Google Calendar and food search wait until you are online. See Install.

Link to this answer

Does it send my data anywhere or track me?

No tracking or analytics. Only four opt-in connections can send anything: encrypted sync, read-only Google Calendar, Open Food Facts search and the SimpleFIN bank feed. The Privacy page lists exactly what each one sends.

Link to this answer

Does this website use cookies or analytics?

No. The site is a set of static files. It sets no cookies, stores nothing in your browser and makes no requests to other sites. The interactive demos run inside the page and keep nothing.

Are the demos on this site the real app?

No. The capture playground and the weight projection are small re-implementations that run in the page, so you can see the behavior before opening the app. The app itself is at Open the app.

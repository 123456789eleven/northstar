The platform

Four layers, one shared model.

Data sits at the bottom. A single ontology gives it meaning. Workflows, analytics and integrations are all built on that same set of objects, so nothing lives in a silo.

Every module reads and writes the same linked objects, so a task can advance a goal and a transaction can be traced to a person or a meal.

Privacy

Your data never leaves your device.

Northstar has no server to send anything to. Entries live in your browser’s own database, and neither the app nor this site makes requests to third parties.

  • No accounts. Nothing to sign up for or log in to.
  • No tracking. No analytics, no ad scripts.
  • No cloud. Data is not uploaded, synced or shared.
  • Works offline. After the first load, no connection is needed.
  • Backup any time. Export everything to a file you keep.

Roadmap

What has shipped, and what is next.

Written plainly. Nothing under “Next” is a promise or has a date.

  1. Capture and search

    Shipped
    • One-line capture for tasks, transactions, meals, weights, wins and journal entries
    • Bulk add for many lines at once
    • Search and command palette, on-device

  2. Planning

    Shipped
    • Planner with week and day views
    • Tasks with recurrence, priorities and goal links; keyboard queue
    • Goals with life, year and quarter horizons and milestones
    • Habits with streaks

  3. Money

    Shipped
    • CSV and OFX/QFX import with duplicate detection and undo
    • Budgets, net worth and merchant category rules
    • Optional SimpleFIN live bank feed (off by default)

  4. Body and food

    Shipped
    • Meal logging with left-today targets and meal templates
    • Optional Open Food Facts search
    • Body weight 7-day trend, rate and goal projection

  5. Reflection

    Shipped
    • Journal with prompts, templates, mood, month map and focus mode
    • Weekly review with digest, ratings trend and lock
    • History timeline and achievements

  6. Command

    Shipped
    • Proposals from six rules with evidence: accept, modify, dismiss and snooze
    • Optional low-risk auto-apply with 24-hour undo

  7. Sync and data

    Shipped
    • End-to-end encrypted sync (AES-256-GCM, passphrase and recovery code)
    • Read-only Google Calendar import
    • JSON backup and one-step restore; .ics and .vcf import

  8. Platform

    Shipped
    • Installable PWA with offline support
    • Demo dataset to explore with fictional data
    • This website, with interactive demos that run in the page

  9. Next

    No dates, no promises
    • Choose a license for the source code.
    • More testing on real phones, especially iOS storage and install behavior.
    • More import formats for bank and calendar data, as needed.
    • Refinements to Command rules based on which proposals turn out useful.
    • A custom domain for this site (the app keeps working at its current address).

Northstar is built by one person for their own use first, so the order of work follows what is useful day to day. There is no changelog by version number yet.
